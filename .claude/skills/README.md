# Skills

The skills in this directory are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
at commit `d81f3a183412e71a5b1e84ca21bc1a35eea03a60` (2026-09-29), MIT licensed
(see `LICENSE-mattpocock-skills`). Only the stable `engineering` and `productivity`
buckets are included; `in-progress`, `misc` and `deprecated` were left out.

Upstream groups skills by bucket; here they are flattened to `.claude/skills/<name>/`
so Claude Code discovers them. Run `/setup-matt-pocock-skills` once to configure the
issue tracker, triage labels and domain doc layout for this repo.
